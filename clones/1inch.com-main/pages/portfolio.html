Questions? Answers.

What is a crypto portfolio tracker?

A crypto portfolio tracker is a tool to monitor your crypto holdings, prices and performance in one place.

Can I track my crypto portfolio across multiple wallets?

Yes, with 1inch Portfolio, you can add multiple wallets.

Can I track my portfolio across both centralized exchanges and self-custody wallets?

Yes. 1inch Portfolio enables you to track assets on both centralized and decentralized platforms.

Can I export my crypto portfolio to CSV or Excel?

Yes, 1inch Portfolio supports CSV export.

Can I track DeFi positions (Aave, Uniswap, Curve)?

Yes, 1inch Portfolio allows you to track your positions on major DeFi protocols.

Is it safe to use a crypto portfolio tracker?

Yes, if it uses read-only API keys or public addresses, like 1inch Portfolio.
